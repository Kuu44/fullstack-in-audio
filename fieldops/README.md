# Promise Desk

The system this course builds, for one customer: **Mato Crafts**, a handmade polymer-clay jewellery studio at Patan Dhoka.

The store already exists. Niyalo shipped catalog, custom orders, cart, sold-out, payments, delivery, and inventory, and ran the ads. The ads were paused when orders got ahead of the bench. Promise Desk is not a second store. Its first job is to stop a promise the makers cannot keep.

Chapter 1 is a charter, not code. Write it in [`01-charter/`](01-charter/README.md).
