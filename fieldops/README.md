# FieldOps Copilot

The accumulating customer-delivery build for [FullStack in Audio](../README.md).

This is not a toy per chapter. Every day's project extends the same system: an incident-and-request triage copilot for a real operations desk. The fictional customer used in the audio is **Harborline Logistics**. The first-release charter from chapter 1 is the source of truth for what this system is allowed to do.

## How work lands here

1. Listen to the chapter audio while running or at the gym.
2. Open the matching project guide. It is a test, not a tutorial.
3. Build from the previous state, or from an empty file if the guide says so.
4. Drop artifacts in this folder (or linked subfolders) and update this table.
5. Record the pass/fail against the rubric in [`docs/progress.md`](../docs/progress.md).

Do not paste a finished solution. If a chapter needs a diagram, put the mermaid or image next to the artifact it explains.
